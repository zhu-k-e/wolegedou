### 0:00–0:40 开场 + 系统长啥样

- **做**：打开首页，**从上到下快速滚一遍这个竖向长页面**（标题 + 5 个依次排列的板块：①学情画像 ②多智能体调度可视化 ③资源生成 ④学情报告 ⑤贡献记忆），让大家一眼看到"一整页就是一条完整闭环"。然后停在板块②，把那个 8 步流水线点亮一遍。
- **屏幕**：竖向页面全貌（5 个板块从上到下堆叠）+ 板块②的 8 步流水线逐步亮起（**诊断→调度→生成→审核→聚焦→裁判→整合→完成**，每步下方都标着"此刻是哪个 AI 在干活"的名字，如学情诊断 Agent / 调度 Agent / 领域专家 Agent / 审核裁判 Agent / 裁判团 / 格式化 Agent）。
- **旁白**："我们这个系统专门帮人学人工智能、学写代码。它不是一个大模型自己闷头干，而是背后有一批各管一摊的 AI 小助手分工合作——一共 11 个领域小助手（这个数字待会儿在第 5 板块'贡献记忆'里能直接看到）。你看这个页面，从上到下就是一条完整闭环：先采集学生情况、多个 AI 一起调度干活、生成专属资料、出分析报告、最后系统自己越用越聪明。其中'多智能体调度'这一步，每一步都标了此刻是哪个 AI 在干活——分析学生水平的、写内容的、挑错的、最后裁判团拍板的。整个流程由一套状态机控制，屏幕上走 8 个主要步骤，背后总共 16 个状态保证不乱。今天这条视频，就带大家把这一整条闭环走一遍。"

### 0:40–2:15 学生情况 + 不同人产出不同（重点段）

- **做**：
  1. 点「TC-001 入门-CS学生」按钮 → 系统**直接套用这组标准画像**（CS 学生 / 入门 / 想深入理解原理），进入生成。PROFILING 这一步**进度条仍会亮**，但因为已有预置画像、不调 LLM 现场诊断，所以一闪而过（这是正常的，目的是保证和提交的证据完全一致）→ 把问题①原话粘进去 → 生成 → 展示三种资料（讲义/操作指南/5测验）。
  2. 再点「TC-020 中级-开发者」「TC-048 进阶-开发者」两个按钮，**同屏对比**三份讲义深浅明显不一样。
  3. 把资料里"已验证"的小标记露出来。
- **屏幕**：TC-001 预置画像直接套用（显示 CS 学生/入门 等字段）+ 三形态资料 + [已验证] 标记；然后 TC-020/048 切过去对比。
- **旁白**："先选一个入门的 CS 学生，问题是'什么是 Token'。系统直接套用这组标准入门画像（CS学生、想深入理解原理），马上进入生成。然后生成三种资料：讲义用生活例子讲、操作指南手把手教、再加 5 道测验。每个知识点旁边标'已验证'，表示这句话是查过资料库确认过的。再看这两个——中级开发者和进阶开发者，问的是同一个 AI 领域（Agent 框架）但难度不同的问题，系统给的资料深浅、风格完全不一样。这就叫'看人下菜'，不同的人给不同的料。（系统也支持为新用户现场分析水平，这里用标准画像是为了稳定和可复现。）"

### 2:15–3:10 三张分析图

- **做**：打开 `/api/report/{TC-001 那次会话的 id}` 那个页，把三张图同屏展示（必须用的是 TC-001 的会话，保证三图是这名学生）。

### 3:10–5:10 答完题系统自动调难度（最精彩段，重点加长）

- **做**：
  1. 做 TC-001 的测验，**故意答错 1~2 题，让正确率低于 85%**（例如 5 题对 3~4 题）→ 看进度条跳到"降难度"那一步 → 系统自动把整份资料**重写成更通俗的版本**（降维后会自动出新一轮测验，或在同一会话重新发起测验）。
  2. **重新做一遍测验，必须 5 题全对（正确率 100%，达到 ≥85% 门槛）** → 系统**额外送一道进阶难题**。
     ⚠️ 关键坑：进阶门槛是正确率 ≥85%。TC-001 测验共 5 题，所以**必须全对**；只要错 1 题（正确率 80% < 85%）反而会触发降维，不是进阶！演示进阶前务必确认 5 题全对。
     💡 实操建议：为避免同一会话里"重做"触发方式不清，最稳是**开两个独立 TC-001 会话**——会话 A 答错演示降维，会话 B 全对演示进阶。前端录前先跑一遍确认哪种方式顺手。
- **屏幕**：测验分数（<85% 和 ≥85%/100% 都要露出来）+ "降难度/加难度"的状态跳变 + 重写后的资料包 / 进阶题。
- **旁白**："重点来了——这不是生成完就完了。学生做完测验，系统看正确率：低于 85% 就自动把内容讲得更浅、更易懂（看，整份资料重写了）；达到 85% 以上就再送一道更难的挑战题。也就是说，系统会**根据学生掌握情况动态调整**，是个会陪你进步的伙伴，不是一次性生成器。"

### 5:10–6:30 挑错 + 查证 + 主动追问（创新点）

- **做**：
  1. 展示"裁判团打分"面板：三个评委分别给"事实对不对 / 逻辑通不通 / 适不适合这个学生"打分。
  2. 露一下"哪段被选为最佳 / 前后段有没有矛盾"的提示。
  3. 露"已验证"标记（TC-001 是 13 条全验证过）。
  4. 展示系统**主动多问你一个问题**的对话。
- **屏幕**：三评委分数面板 + 综合得分 + 已验证标记 + 系统主动追问的对话框。
- **旁白**："内容生成完，不是直接交差，而是过三道关：一个查事实对不对、一个挑逻辑漏洞、一个看适不适合这个学生。三个分数加权算总分，再交叉比对前后段有没有矛盾。每个知识点都去资料库查证过（看'已验证'标记）。而且系统还会主动追问你，引导你往下想，不是死板地等你问。这就是为什么我们的内容幻觉率只有 3%——多个 AI 互相挑错、查证，比一个大模型自己审自己靠谱。"

### 6:30–7:20 系统越用越聪明（自我进化 + 领域全景）

- **做**：打开"系统自我进化记录"页（数据来自 `/api/memory_stats`），**先把 Agent 贡献分排行榜往下滚一下，露出 11 个 Agent 的名字**，停留 20~30 秒。
- **屏幕**：**当前 α 值**（演示模式下固定显示 0.3 并配阶梯规则文字；真实后端按任务量显示当前值）+ α 阶梯**规则说明**（冷启动 0.9 → ≥50 任务 0.7 → ≥100 任务 0.5 → ≥200 任务 0.3）+ **11 个 Agent 贡献分排行（名字带出 10 个子方向：LLM基础、Prompt工程、LangChain、RAG、向量数据库、Agent框架、HuggingFace、模型微调、项目部署、代码调试）** + 最近贡献流 + 淘汰记录（**可能为空，如实显示"暂无淘汰"**，不要伪造）。
- **旁白**："最后看这套系统怎么自我进化：每次任务都记下来谁干得好、动态调权重（α 从冷启动 0.9 随任务量逐步降到 0.3），干得差的 AI 助手会被淘汰。这是完整闭环的最后一环。注意：视频里 α 显示的是当前值，阶梯是系统的调整规则，不是已经发生过的历史曲线——我们不造假。另外注意看这 11 个 Agent 的名字，它们覆盖了 AI/软件开发领域的 10 个子方向；刚才视频只跑了 LLM基础 和 Agent框架，但系统本身是支持跨领域泛化的。"

### 7:20–8:10 合规 + 真实成绩（诚实段）

## 五、千万别踩的坑（录完对着查）

1. **覆盖率只能说 87.9%**，绝对不许说"90% 以上""全覆盖"——评委一对证据就穿帮。
2. **三道题必须用上面原话**，学生画像点按钮选，别改问题、别自己编画像。
3. **三张分析图缺一不可**（盲区/难度/路径），且必须用 TC-001 的会话 id。
4. **降维演示只需错 1 题以上（正确率<85%），进阶演示必须 5 题全对（正确率=100%≥85%）**，别再出现 0% 那种尴尬画面，也别在想演示进阶时只答对 4 题（80%<85% 反而触发降维）。
5. **参考资料列表别重复刷同一篇**（录前确认后端修好了）。
6. **"查看原始 JSON（调试）"横幅必须藏掉**。
7. **TC-048 必须能跑出结果**，别留"待回答"窟窿。
8. 别展示报错、别展示"强制放行"那种流程。
9. 隧道断了就让后端重开拿新网址，从断点接着录，别留黑屏。
10. **总时长掐在 10 分钟以内**（本版控 9:30），把所有"等待生成"的空画面剪掉。
11. 文件名建议：`作品演示视频_领域知识个性化生成与多智能体协同决策系统.mp4`
12. **α 和淘汰记录要诚实**：屏幕上 α 只显示当前实时值（演示模式下固定显示 0.3，并配阶梯规则文字；真实后端按任务量显示），阶梯是规则说明不要做成"已发生历史动画"；淘汰记录若为空就如实说"暂无淘汰"，绝不伪造数据——竞赛铁律"假不行"。
