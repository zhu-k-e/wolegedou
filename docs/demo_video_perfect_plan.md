## 三、录制技术准备（前后端两台机器 / 勿默认同屏）

### 3.1 后端启动（📌 本子 v4.0 §4.2.4 写错，照本子会失败）
```bash
# 必须在项目根目录执行（main.py 用绝对导入 from backend.xxx）
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
# ❌ 错误写法（本子原版）：cd backend && uvicorn main:app  → ModuleNotFoundError
```

### 3.2 前端连后端的真实端点（📌 本子 v4.0 写错，照本子连不上）
| 能力 | ✅ 真实端点 | ❌ 本子写的 |
|---|---|---|
| 主流程（学情→生成→审核→裁判→交付） | `POST /api/ask` | 同（对） |
| 实时状态推送（FSM 流/中间产物） | **`WebSocket /ws/{task_id}`**（无 /api 前缀） | `/api/ws/{task_id}` ❌ |
| 任务状态轮询 | `GET /api/status/{task_id}` | 同（对） |
| 知识库健康 | `GET /api/kb/health` | `/api/kb/stats` ❌（会 404） |
| 可视化报告 | `GET /api/report/{session_id}` | — |
| 贡献记忆 | `GET /api/memory_stats` | — |

> ⚠️ 前端若用 `socket.io-client` 连 WS，**必然握手失败**（后端是 FastAPI 原生 WebSocket）。请用浏览器原生 `WebSocket` API。
> ⚠️ 本地联调走 Cloudflare 临时隧道：每次重启域名会变，旧 URL 立即失效，重启后须重新抓 `https://*.trycloudflare.com` 再连。

### 3.3 录屏（OBS Studio）
- 1080p / 30fps，采集「系统音频 + 麦克风旁白」。
- **推荐方式**：整套在你本机录。浏览器打开队友部署的前端（走 cloudflared 隧道 URL）放左 60%，你的后端终端放右 40%，OBS 录本机桌面 → 零同步问题。
- 旁白边操作边讲「现在输入的是哪种学情」「现在哪个 Agent 在工作」「生成了哪几种资源」。

### 3.4 预演与控时
- 正式录前空跑 3 遍：3 个问题各跑一次，确认都在 ~2 分钟内出结果（避免 API 超时卡顿）。
- 总时长严格 **≤ 10:00**，建议 **9:30** 收尾留余量。OBS 开「录制计时」。
- 剪辑掉所有等待段（只保留输入、关键状态跳变、输出结果），真实等待压缩到 5–10 秒/处。
- 隧道若中途断：立刻重启 cloudflared 拿新 URL → 前端重连 → 从断点场景续录（不要硬扛黑屏）。

## 七、避坑与质检清单（录完必查 · 含 v2 全部 bug 修复）

5. **修复参考文献重复堆砌**：同一文档重复列出十几次像溯源 bug，录制前让后端去重（`knowledge_refs`）。
6. **隐藏调试 JSON 面板**：「查看原始报告 JSON（调试）」横幅必须在发布/录制前移除。
7. **TC-048 稳定性**：确保「请设计一个多 Agent 协作流程…」能稳定跑出结果，不留"待回答"缺口。
8. **不要展示报错/强制放行流程**；TC-048 的 `low_confidence_passed` 是正常低置信通过，旁白说明即可。
9. **隧道断了立刻重启换 URL**，前端重连后从断点续录；不留黑屏/卡顿。
10. 三个问题必须都跑通且闭环完整，无「生成到一半没了」的片段。
