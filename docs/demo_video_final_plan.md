## 三、录制实操要点（给队友/你本人）

1. **固定 session**：录制全程锁定一个 `session_id`，别用 `Date.now()` 每次新建，否则报告零散。
2. **先预热后录制**：预热轮（降维+进阶）不进正片，只为填数据和热 KB。
3. **剪等待**：正片里问答的 84 秒等待段全部剪掉，只留「提交→出结果」瞬间 + 旁白。
4. **真后端验证**：开录前确认前端状态来自 `GET /api/status` 轮询、接口返回 200，且能看到真实 KB 检索日志（说明连的是真后端）。
5. **横幅与调试信息**：录制时隐藏任何后端原始 JSON / 调试横幅，保持界面干净。
6. **三组数据**：主线用 TC-001（LLM 基础，问题「什么是 Token？」），热力图/路径最饱满；若想再展示跨领域，可在同一 session 额外跑 TC-020（ReAct）/ TC-048（多 Agent 协作，进阶）快速问答（不进正片，只落库）。三组问题原文均在 `data/io_examples/bm_TC-0XX_io.json`，录制时严格照念，不得改写。
7. **指标取值**：所有百分比从最新 benchmark 报告念出，写入本计划占位符，录制时照念。
