## 二、缺失 / 有问题的功能（录制前必须修，否则丢分或露怯）

### 🔴 严重缺口 1：缺「资源难度匹配曲线」

- **问题**：报告页只有 3 个 tab——**画像 / 热力图 / 学习路径**，**没有「资源难度匹配曲线」**。
- **后果**：赛题答题要求 (3)① 明确要写「资源难度匹配曲线」，缺它直接扣完整性/实用价值分。
- **根因**：后端 `/api/report/{session_id}` 已经返回 `difficulty_match`（`backend/api/routes/report.py:155-209`），前端没画。
- **修复**：前端在报告区增加第 4 个 tab 或同屏 chart，用 `student_level`（蓝线）和 `resource_difficulty`（红线）画折线图，并显示 `overall_match_rate`。

### 🔴 严重缺口 2：「实操指南」展示不清晰

- **问题**：创建表单勾了「学习讲义、实操指南、测试题」，但输出区只看到「学习讲义」和「测试题」两块，**没见过独立的「实操指南」卡片/标签**。
- **后果**：赛题要求「至少 3 种形态」，评委若只看见 2 种会被判功能缺失。
- **修复**：在「个性化学习资源」区把三形态做成并列 tab/卡片，让讲义、实操指南、测验能同屏切换，而不是把实操内容混在讲义里。

### 🔴 严重缺口 3：没有「裁判团三维度结论面板」

- **问题**：方案书和脚本里要吹的「Verifier / Skeptic / Evaluator + fact_accuracy / logic_completeness / pedagogical_fit + 加权 0.35/0.35/0.30」面板，**前端真实页面完全没有**。
- **后果**：创新点「辩论与交叉验证消除幻觉」没有可视化证据，只能嘴上说，说服力大减。
- **根因**：后端 `judge_verdict` 返回了这些数据（`ask.py:227-266` 会写入 task_metrics），但前端没解析展示。
- **修复**：新增一个「裁判裁决详情」卡片/折叠面板，展示：
  - 事实准确度、逻辑完整度、教学适配度三条分数
  - 综合 verdict（passed / revise / low_confidence_passed）
  - 溯源验证率 verification_rate

### 🔴 严重 bug 4：测验动态迭代阈值显示错误

- **问题视频证据**：
  - 3:10 处，答对 3/5（正确率 **60%**），前端显示「**✅ 正确率达标，触发自适应升档**」。
  - 3:45 处，答对 2/5（正确率 **40%**），前端显示「⚠️ 正确率低于 60%，触发自适应降档」。
- **真实后端逻辑**：`backend/api/routes/quiz.py:41` 与 `backend/core/orchestrator.py:1254` 都是 **`< 0.85 降维，否则进阶`**。
- **后果**：60% 在后端会被 REDIMENSION（降维），前端却显示「升档」——**演示与真实逻辑直接矛盾**，评委一测就穿帮。
- **修复**：前端不要自己定阈值，直接显示后端 `/api/quiz_submit` 返回的 `action` 字段；如果前端硬要提示阈值，必须统一写 **85%**。

### 🟡 必须修 5：调试 JSON 横幅还在

- **问题**：报告页底部有黄色按钮「**查看原始报告 JSON**」。
- **后果**：v2 片子就因为暴露调试面板被批，发布/录制前必须隐藏。

### 🟡 必须修 6：知识引用重复 / 丑陋

- **问题**：「关联知识」里出现：
  - `Google GenAI Best Practices_..._finetuning-with-funct.ipynb.md`（超长文件名）
  - `（知识库补全）` 重复出现多次
- **后果**：像溯源 bug，影响专业感。
- **修复**：后端去重 + 前端对长文件名截断/美化，占位符「知识库补全」不要显示。

### 🟡 建议修 7：启发式追问没地方展示

- **问题**：方案书里写的「系统主动追问 / 衍生问题」，真实页面上没找到对应 UI。
- **后果**：创新点 答题4② 只能空口说。
- **修复**：在结果页加一个「系统想继续问你」的气泡或侧边栏。

### 🟡 表述不一致 8：8 步名称与脚本对不上

前端真实标签：
> 学情诊断 / Agent调度 / 内容生成 / 质量审核 / 结果聚合 / 裁判评估 / 资源整理 / 任务完成

脚本之前写的是：
> 诊断→调度→生成→审核→聚焦→裁判→整合→完成

需要统一为前端真实文案，避免旁白和画面字幕打架。
