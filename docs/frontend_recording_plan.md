# 前端演示视频录制方案（v1 · 基于本子 v4.0 增强）

> 用途：发给**前端队友**照着录 10 分钟演示视频。本文档已对齐后端真实代码（2026-08-19 核实），
> 凡与本子 v4.0 冲突处一律以「📌 正确做法」为准。
> 评分映射：完整性 30 / 创新性 25 / 用户体验 15 / 实用价值 30 / 数据合规（硬性）。

---

## 0. 录制前必读（否则系统跑不起来）

### 0.1 后端启动（📌 本子 v4.0 §4.2.4 写错，照本子会失败）
```bash
# 必须在项目根目录执行（main.py 用绝对导入 from backend.xxx）
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
# ❌ 错误写法（本子原版）：cd backend && uvicorn main:app   → ModuleNotFoundError
```

### 0.2 前端连后端的真实端点（📌 本子 v4.0 写错，照本子连不上）
| 能力 | ✅ 真实端点 | ❌ 本子写的 |
|---|---|---|
| 主流程（学情→生成→审核→裁判→交付） | `POST /api/ask` | 同（对） |
| 实时状态推送（FSM 流/中间产物） | **`WebSocket /ws/{task_id}`**（无 /api 前缀） | `/api/ws/{task_id}` ❌ |
| 健康检查 | `GET /api/status/{task_id}` | 同（对） |
| 知识库健康 | `GET /api/kb/health` | `/api/kb/stats` ❌（会 404） |

> ⚠️ 前端若用 `socket.io-client` 连 WS，**必然握手失败**（后端是 FastAPI 原生 WebSocket）。请用浏览器原生 `WebSocket` API。
> ⚠️ 本地联调走 Cloudflare 临时隧道：每次重启域名会变，旧 URL 立即失效，重启后须重新抓 `https://*.trycloudflare.com` 再连。

### 0.3 学情画像怎么来（📌 别偷懒硬塞）
- **问题文本**：演示者手动输入（可预打在输入框）。
- **原始输入**（学历/专业/测试成绩/自评）：前端表单录入（可预填，属"学习者真实数据"）。
- **学情画像 JSON**（10 领域掌握度等）：**由后端 Analyzer Agent 现场 LLM 生成**，用户给定字段原样保留、LLM 只补缺失。
- ❌ **禁止**走"直接传 `profile` 字段跳过诊断"的捷径——否则学情诊断能力在镜头前没展示，白白丢分。

### 0.4 KB 数字说明
- 实际 chunk 数 **34154**（实测 `vectors.npy` shape `(34154,1024)`）。本子/旧日志写的 30532 是过期数。
- 视频里以**真实运行系统显示的数字**为准，不用管文案数字。

## 1. 总体录制策略（核心：用 3 组画像"一镜多用"）

**不要**把 P1/P3/P5 当 3 个互不相关的 demo 分开录。
**要**把它们当成「**同一个问题的 3 种答案**」做对比——一个领域问题，三个画像产出三种资源，
个性化差异直接撞进评委眼睛，比分三个不相关场景更有冲击力。

| 维度 | 策略 |
|---|---|
| 个性化证明 | 至少安排 1 个「同问题三画像」对比镜头（见分镜 4.5） |
| 创新证明 | 分镜 3 放慢讲透「审核/裁判 + 辩论」（创新性 25 分全靠这段） |
| 可信证明 | 每个资源画面都露「溯源链 [ref:xxx] 标绿」 |
| 闭环证明 | 分镜 5 必须真录到「答题→降维/进阶切换」 |
| 诚实加分 | 分镜 6 指标盘如实标 87.9% 未达标（竞赛铁律：低可接受、假不行） |

## 2. 增强版分镜脚本（总时长 ≤10 分钟）

| 分镜 | 时长 | 画面内容 | 必捕点（评委得分点） |
|---|---|---|---|
| **1 架构总览** | 0:00–1:00 | 四层架构图展开 + FSM 状态流转动画（**16 态**：主9+异常2+延伸5） | 全链路闭环可视；点出"多 Agent 协同 vs 单体模型" |
| **2 场景一 P1 零基础文科生** | 1:00–3:00 | 左侧表单填背景（无编程）→ 输问题"什么是大语言模型"→ **Analyzer 现场生成画像**（10 领域掌握度<0.25）→ FSM 流 → 输出讲义(生活类比)+实操指南(环境安装)+判断题 | ①画像**系统生成**全过程 ②降维(类比) ③溯源链标绿 |
| **3 场景二 P3 中级开发者** | 3:00–5:30 | 表单填"会 Flask/Python，不懂 RAG"→ 问题"RAG top_k 怎么设/怎么优化"→ **放慢展示审核 3 角色评分面板 + 裁判 2:1 分歧 + 少数方举证/多数方回应（辩论）** → 输出分析级实操指南+分析题 | ①**辩论/交叉验证**（核心创新）②溯源链 ③适配(分析级) |
| **4 场景三 P5 转岗/算法工程师** | 5:30–7:30 | 表单填"理论强、缺工程"→ 问题"用 LangChain 搭完整 RAG 应用"→ 代码补全+调试 → **露 AST 静态分析标出 eval/exec 危险调用** → 跨知识点联动出题 + 启发式追问 | ①代码安全门(AST) ②跨知识点联动 ③追问闭环 |
| **4.5 同问题三画像对比（强烈建议加）** | 7:30–8:00 | 同一问题"RAG 检索 top_k 设多少"分别喂 P1/P3/P5 → 三份资源**并排**：判断题 vs 分析题 vs 代码补全 | 个性化适配的"一击必杀"证据 |
| **5 动态迭代闭环** | 8:00–9:00 | 答题面板：P1 正确率<60%→降维(加类比/拆步)；P3≥85%→进阶挑战 | 证明"不是一次性生成器"，而是持续适应的学习伙伴 |
| **6 溯源链 + 指标总结** | 9:00–10:00 | 溯源链表格 + 三项指标仪表盘：幻觉 3.0% / 适配 100% / 覆盖 87.9%（标"未达标·诚实披露"） | 量化优势 + 诚实披露显严谨 |

## 3. 逐镜 Checklist（前端队友打勾用）

**分镜 1**
- [ ] 架构图四层（用户交互/协同调度/知识支撑/持久化）都出现
- [ ] FSM 状态流动画播放（标注 16 态）
- [ ] 口播点出"多 Agent 协同解决单体模型自己审自己"的痛点

**分镜 2（P1）**
- [ ] 表单背景为"零基础文科生/无编程"
- [ ] **Analyzer 生成画像的过程可见**（不要跳到已生成）
- [ ] 输出含：生活类比讲义 + 环境安装实操指南 + 判断题
- [ ] 资源上 [ref:xxx] 溯源标绿可见

**分镜 3（P3）——最重要**
- [ ] 审核 3 角色（Verifier/Skeptic/Evaluator）评分面板可见
- [ ] 出现**裁判 2:1 分歧 + 少数方证据 + 多数方回应**（辩论过程）
- [ ] 输出为分析级内容（非判断题）
- [ ] 溯源链标绿

**分镜 4（P5）**
- [ ] 出现代码块 + AST 静态分析标记的警告（eval/exec 等）
- [ ] 出现跨知识点联动题 或 启发式追问对话
- [ ] 画像更新动画（knowledge_state 变化）

**分镜 4.5（对比）**
- [ ] 同一问题三画像 → 三份资源并排
- [ ] 资源类型差异一眼可辨（判断/分析/代码）

**分镜 5（迭代）**
- [ ] 答题正确率数值可见（<60% / ≥85%）
- [ ] 降维/进阶切换动画或画面过渡

**分镜 6（指标）**
- [ ] 三项指标盘：幻觉 3.0% / 适配 100% / 覆盖 87.9%
- [ ] 87.9% 标注"未达标·诚实披露"（不要改成 90%/95%）
