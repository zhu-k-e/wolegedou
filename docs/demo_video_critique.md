# 演示视频评审意见

> 评审对象：`8bfbbe50a5fbe52366b88e2bf3fdb397.mp4`（3 分 41 秒，960×528）
> 评审时间：2026-08-16

## 一、核心结论

视频能跑通"画像 → Agent 调度 → 内容生成 → 裁判评估 → 练习测验"一条链路，**但严重偏离了我们确定的演示计划（TC-001/020/048），且缺少关键可视化（热力图、难度曲线、学习路径）**。当前素材不足以支撑 10 分钟竞赛演示视频，需要补录或重剪。

---

## 二、严重问题（必须改）

### 1. 演示问题偏离既定基准
- **当前视频演示的是 RAG 问题**（标题可见"RAG（检索增强生成）技术讲义"）。
- 我们之前明确约定：镜头里要问的 **3 个问题必须严格对应 `TC-001/020/048`**：
  - TC-001："在大语言模型中，什么是 Token？它与'词'有什么区别？"
  - TC-020："请解释 ReAct 范式的工作流程，Thought-Action-Observation 循环是如何进行的？"
  - TC-048："请设计一个多 Agent 协作流程，包含规划 Agent、执行 Agent、审查 Agent，说明数据如何流转。"
- **影响**：如果评委把视频里的问题和我们提交的 `test_cases_100.json` / I/O 示例对不上，会被质疑真实性。

### 2. 关键可视化全部缺失
你提到的热度图确实没有，和它一起缺的还有：
| 缺失项 | 后端接口 | 竞赛评分影响 |
|---|---|---|
| 盲区热力图 | `/api/report` | 直接对应"学情画像"与"可视化"得分点 |
| 难度曲线 | `/api/report` | 体现自适应升降维能力 |
| 学习路径/知识图谱 | `/api/report` | 体现个性化学习规划 |
| 历史进步趋势 | `/api/report` | 体现长期学习追踪 |

### 3. 时长严重不足
- 当前 **3 分 41 秒**，赛题要求 **10 分钟演示视频**。
- 剪掉等待和重复滚动后，有效内容大约只有 2 分多钟。

### 4. 测试结果观感差
- 视频中 5 道测验题全部答错，最终显示 **"正确率：0.00%"**。
- Demo 里出现 0 分会显得系统教学质量差，或者用户画像不准。建议补录时：
  - 要么故意展示"先错后改进"的完整闭环，
  - 要么至少答对 3~4 题，体现系统有效。

### 5. 参考文献重复堆砌
- "多 Agent 裁判结果"下方的参考文献，**把同一份 `Google GenAI Best Practice` 重复列出了十几次**。
- 这会让评委觉得引用去重/格式化有问题，或者存在伪溯源。

## 三、中等问题（建议改）

### 6. 缺少自然语言画像诊断
- 视频里直接用手动点标签的方式完成画像，没有展示：
  - 用户在输入框里用自然语言描述"我是初学者，想学习 RAG..."
  - 系统如何自动解析为结构化画像。
- 这弱化了我们后端 `ProfileAgent` 的卖点。

### 7. 缺少进阶/降维迭代
- 没有展示：
  - 学生答错后，系统如何降低难度、补充基础；
  - 学生表现好后，如何提升难度、推荐进阶内容。
- 这是"个性化"和"自进化"的核心卖点，视频里完全没体现。

### 8. WebSocket 实时性证据不足
- Agent 流程有进度动画，但看起来更像前端本地动画，**没有明显展示后端真实推送**（如消息时间戳、任务 ID、实时日志）。
- 建议补录 `/ws` 连接状态或网络面板一闪而过的镜头。

### 9. 没有片头片尾
- 视频直接切入界面，缺少：
  - 系统名称/团队信息；
  - 本次演示目标说明；
  - 结尾总结与指标数据。

### 10. 缺少指标/技术栈展示
- 没有展示 4 项指标（覆盖率/适配率/幻觉率/谬误率）、11 Agent 架构图、模型档位说明。
- 这些是方案书和代码里的亮点，视频里不提很吃亏。

## 四、做得好的地方（保留）

1. **Agent 协同流程可视化清晰**：7 个步骤（PROFILING → FORMATTING）完整展示。
2. **裁判团结果展示到位**：事实/逻辑/远见三维度 + 置信度，体现了 anti-hallucination 设计。
3. **三种资源形态都出现了**：讲义、代码示例、测验，符合"多形态资源"的卖点。
4. **学习反馈入口存在**："内容很详细 / 内容有误 / 需要更个性"三个按钮展示了反馈闭环。

## 五、修改建议（优先级排序）

### 方案 A：小修（再补录 3~5 段，剪辑到 8~10 分钟）
1. 补录 **TC-001、TC-020、TC-048 三个问题**的完整问答流程，严格使用基准原文。

3. 补录一段自然语言输入画像（例如："我是文科生，没有编程基础..."）。
4. 补录一段"答错后降维"或"答对后进阶"的迭代镜头。
5. 重新录制测验，确保正确率 ≥60%。
6. 加 30 秒片头 + 30 秒片尾（系统名 + 核心指标 + 架构图）。
