# 演示视频录制脚本（给前端同学 · 大白话版）

> 这份是给你（前端）照着录的。技术细节不用管，只管**按时间轴点按钮、展示画面、念旁白**。
> 背后原理那份（`demo_video_perfect_plan.md`）是给评委和后端看的，你不用读。
> **死规定**：① 视频总长不能超过 10 分钟；② 三组学生只能用 TC-001 / TC-020 / TC-048，问题文字一个字都不能改；③ 覆盖率只能说 87.9%，不能吹成 90%。

---

## 一、录之前先确认（缺一样就先别录，找后端）

- [ ] 页面上有「盲区热力图 + 难度曲线 + 学习路径」这三张图能正常显示（这是评委硬要看的，少一张直接丢分）
- [ ] 页面上有那个「处理进度动画」——点完问题后，会一步一步亮起来（诊断→生成→审核→聚焦→裁判→整合→完成），一共 **8 步**（这是屏幕上看到的；背后状态机总共有 16 个状态，你不用管）
- [ ] 一个问题能同时（或顺次）看到三种东西：讲义 + 操作指南 + 5 道小测验
- [ ] 做完测验后，系统会根据正确率**自动调整难度**（低于 85% 就讲得更通俗；达到 85% 以上——TC-001 是 5 题须全对——才加一道难题）
- [ ] 页面上能显示「裁判团打分」和「参考资料是否查证过」的标记
- [ ] 能展示「学生画像」：点 TC 预置按钮直接套用标准画像（CS学生/开发者等）；新用户首问时系统也能现场分析出水平（两种都能演示）
- [ ] 有个「系统自我进化记录」页面（显示哪些 AI 助手贡献多、有没有被淘汰）
- [ ] **把那个「查看原始 JSON（调试）」的小横幅藏掉**（评委看见像没做完，必须关）
- [ ] 参考资料列表**别重复刷同一篇十几遍**（后端会修，录前确认修好了）
- [ ] TC-048 那道题（"设计多 Agent 协作流程"）能稳定出结果，别卡在"待回答"

## 二、怎么连后端（简单版）

1. **后端启动**（让后端同学跑，你不用管命令，但要知道他在根目录跑，不是进 backend 文件夹）：
   ```
   uvicorn backend.main:app --host 0.0.0.0 --port 8000
   ```
2. **你前端连的地址**：
   - 提交问题： `POST /api/ask`
   - 实时进度： WebSocket 地址是 **`/ws/{任务id}`**（注意：前面**没有** `/api`！本子写错了，照本子连不上）
   - 查状态： `GET /api/status/{任务id}`
   - 那三张图： `GET /api/report/{会话id}`
   - 系统进化记录： `GET /api/memory_stats`
   - ⚠️ 连进度千万别用 socket.io 那套，后端不支持，会连不上。用浏览器原生的 WebSocket 就行。
3. **联调走隧道**：后端会给一个临时网址（每次重启都变），你把前端 API 地址指过去，先试一下能通再录。

## 三、分镜头脚本（总时间 ≤10 分钟，严格按这个来）

> 每段左边是"你做什么"，中间是"屏幕该出现啥"，右边是"你嘴上怎么说（旁白）"。

### 0:00–0:45 开场 + 系统长啥样
- **做**：打开首页，展示系统架构图（四层）和那 11 个 AI 助手的小卡片，放一下那个进度动画（一步一步亮，共 8 步）。
- **屏幕**：架构图 + 11 个小助手名字 + 进度动画（一步一步亮，共 8 步：诊断→生成→审核→聚焦→裁判→整合→完成）。
- **旁白**："我们这个系统，是专门帮人学人工智能、学写代码的。背后不是一个大模型自己闷头干，而是有 11 个各管一摊的 AI 小助手分工合作——比如有专门分析学生水平的、有专门写内容的、有专门挑错的。一个问题从进来到出结果，屏幕上会经过 8 个主要步骤（背后状态机总共 16 个状态，保证流程可控，但进度条上只显示 8 步）。今天这条视频，就带大家看一遍：不同水平的学生进来 → 多个 AI 一起干活的过程 → 最后生成专属学习资料，整个闭环。"

### 0:45–2:30 学生情况 + 不同人产出不同（重点段）
- **做**：
  1. 点「TC-001 入门-CS学生」按钮 → 系统**直接套用这组标准画像**（CS 学生 / 入门 / 想深入理解原理），PROFILING 这一步会很快跳过（因为是预置画像、不是现场 LLM 诊断）——这是正常的，目的是保证和提交的证据完全一致 → 把问题①原话粘进去 → 生成 → 展示三种资料（讲义/操作指南/5测验）。
  2. 再点「TC-020 中级-开发者」「TC-048 进阶-开发者」两个按钮，**同屏对比**三份讲义深浅明显不一样。
  3. 把资料里"已验证"的小标记露出来。
- **屏幕**：TC-001 预置画像直接套用（显示 CS 学生/入门 等字段）+ 三形态资料 + [已验证] 标记；然后 TC-020/048 切过去对比。
- **旁白**："先选一个入门的 CS 学生，问题是'什么是 Token'。系统直接套用这组标准入门画像（CS学生、想深入理解原理），马上进入生成。然后生成三种资料：讲义用生活例子讲、操作指南手把手教、再加 5 道测验。每个知识点旁边标'已验证'，表示这句话是查过资料库确认过的。再看这两个——中级开发者和进阶开发者，问的是同一个 AI 领域（Agent 框架）但难度不同的问题，系统给的资料深浅、风格完全不一样。这就叫'看人下菜'，不同的人给不同的料。（系统也支持为新用户现场分析水平，这里用标准画像是为了稳定和可复现。）"

> ⚠️ TC-001 那个按钮点完，界面上**只显示"CS 学生"**，别手滑写出"有 Python 基础"之类的话（那不是真实画像）。

### 2:30–3:30 三张分析图
- **做**：打开 `/api/report/{会话id}` 那个页，把三张图同屏展示。
- **屏幕**：盲区热力图 + 难度曲线 + 学习路径图，**三张都要在**。
- **旁白**："这是系统给这个学生出的三张分析图：哪块是知识盲区（热力图）、资料难度匹配得合不合理（曲线）、该按什么顺序学（路径图）。评委要求必须有的三张图，齐了。"

### 3:30–5:30 答完题系统自动调难度（最精彩段，重点加长）
- **做**：
  1. 做 TC-001 的测验，**故意答错 1~2 题，让正确率低于 85%**（例如 5 题对 3~4 题）→ 看进度条跳到"降难度"那一步 → 系统自动把整份资料**重写成更通俗的版本**。
  2. **重新做一遍测验，必须 5 题全对（正确率 100%，达到 ≥85% 门槛）** → 系统**额外送一道进阶难题**。
     ⚠️ 关键坑：进阶门槛是正确率 ≥85%。TC-001 测验共 5 题，所以**必须全对**；只要错 1 题（正确率 80% < 85%）反而会触发降维，不是进阶！演示进阶前务必确认 5 题全对。
- **屏幕**：测验分数（<85% 和 ≥85%/100% 都要露出来）+ "降难度/加难度"的状态跳变 + 重写后的资料包 / 进阶题。
- **旁白**："重点来了——这不是生成完就完了。学生做完测验，系统看正确率：低于 85% 就自动把内容讲得更浅、更易懂（看，整份资料重写了）；达到 85% 以上就再送一道更难的挑战题。也就是说，系统会**根据学生掌握情况动态调整**，是个会陪你进步的伙伴，不是一次性生成器。"

### 5:30–7:00 挑错 + 查证 + 主动追问（创新点）
- **做**：
  1. 展示"裁判团打分"面板：三个评委分别给"事实对不对 / 逻辑通不通 / 适不适合这个学生"打分。
  2. 露一下"哪段被选为最佳 / 前后段有没有矛盾"的提示。
  3. 露"已验证"标记（TC-001 是 13 条全验证过）。
  4. 展示系统**主动多问你一个问题**的对话。
- **屏幕**：三评委分数面板 + 综合得分 + 已验证标记 + 系统主动追问的对话框。
- **旁白**："内容生成完，不是直接交差，而是过三道关：一个查事实对不对、一个挑逻辑漏洞、一个看适不适合这个学生。三个分数加权算总分，再交叉比对前后段有没有矛盾。每个知识点都去资料库查证过（看'已验证'标记）。而且系统还会主动追问你，引导你往下想，不是死板地等你问。这就是为什么我们的内容幻觉率只有 3%——多个 AI 互相挑错、查证，比一个大模型自己审自己靠谱。"

### 7:00–8:00 系统越用越聪明（自我进化）
- **做**：打开"系统自我进化记录"页，停留 20~30 秒。
- **屏幕**：α 那个阶梯（0.9→0.7→0.5→0.3）+ 哪些 AI 助手贡献多（排行榜）+ 最近干了啥 + 有没有被淘汰的。
- **旁白**："最后看这套系统怎么自我进化：每次任务都记下来谁干得好、动态调权重，干得差的 AI 助手会被淘汰。用的越久，系统越聪明、越会挑人干活。这就是完整闭环的最后一环。"

### 8:00–9:00 合规 + 真实成绩（诚实段）
- **做**：展示指标盘。
- **屏幕**：四个数——幻觉 3.0% / 适配 100% / 谬误 0% / **覆盖率 87.9%（旁边标"未达标"）**；资料库标 34154 段。
- **旁白**："我们系统本地部署、数据隔离、不收集个人隐私。成绩如实说：幻觉率 3%、适配 100%、谬误 0%，都是达标或优秀的；只有覆盖率 87.9%，离赛题要求的 90% 还差一点——我们如实标'未达标'，不造假。竞赛规则是'低分可以，造假不行'，我们宁可诚实扣几分。"

### 9:00–10:00 收尾
- **做**：快速回放一遍闭环。
- **屏幕**：学情 → 调度 → 资料 → 反馈 → 自我进化，串起来。
- **旁白**："回顾一下：不同学生进来，多个 AI 协同调度，生成专属资料，再根据答题反馈动态调整、自我进化。这就是我们的完整闭环。谢谢大家。"

## 四、三道题怎么填（照抄，一个字别改）

> 这三组就是 TC-001 / TC-020 / TC-048。画像（学生情况）点按钮自动选好，**问题文字必须原样粘贴**，别自己发挥。

**题① 入门档（TC-001）** — 点「TC-001 入门-CS学生」按钮，问题粘这句：
> 在大语言模型中，什么是 Token？它与"词"有什么区别？

**题② 中级档（TC-020）** — 点「TC-020 中级-开发者」按钮，问题粘这句：
> 请解释 ReAct（Reasoning + Acting）范式的工作流程，Thought-Action-Observation 循环是如何进行的？

**题③ 进阶档（TC-048）** — 点「TC-048 进阶-开发者」按钮，问题粘这句：
> 请设计一个多 Agent 协作流程，包含规划 Agent、执行 Agent、审查 Agent，说明数据如何流转。

> 注意：TC-048 生成完可能会显示"低置信通过"——这是正常的，不是出错，旁白说一句"正常通过"就行，别当 bug 处理。

## 五、千万别踩的坑（录完对着查）

1. **覆盖率只能说 87.9%**，绝对不许说"90% 以上""全覆盖"——评委一对证据就穿帮。
2. **三道题必须用上面原话**，学生画像点按钮选，别改问题、别自己编画像。
3. **三张分析图缺一不可**（盲区/难度/路径）。
4. **降维演示只需错 1 题以上（正确率<85%），进阶演示必须 5 题全对（正确率=100%≥85%）**，别再出现 0% 那种尴尬画面，也别在想演示进阶时只答对 4 题（80%<85% 反而触发降维）。
5. **参考资料列表别重复刷同一篇**（录前确认后端修好了）。
6. **"查看原始 JSON（调试）"横幅必须藏掉**。
7. **TC-048 必须能跑出结果**，别留"待回答"窟窿。
8. 别展示报错、别展示"强制放行"那种流程。
9. 隧道断了就让后端重开拿新网址，从断点接着录，别留黑屏。
10. **总时长掐在 10 分钟以内**（建议 9 分半），把所有"等待生成"的空画面剪掉。
11. 文件名建议：`作品演示视频_领域知识个性化生成与多智能体协同决策系统.mp4`
