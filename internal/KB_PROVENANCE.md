# 知识库来源与版权合规说明

## 1. 知识库内容来源

本系统使用的预计算向量知识库（`data/numpy_kb/`）源于**公开 AI / LLM 技术文档与社区资料的批量抓取与整理**，覆盖以下类型公开来源：

- 大语言模型（LLM）官方技术博客与文档
- 开源框架（如 LangChain、HuggingFace Transformers）的公开教程与 API 文档
- 学术界与社区发布的 Prompt 工程、RAG、Agent、模型微调等技术文章
- 公开课程讲义与教学材料

**原始来源 URL 在构建时未逐条持久化**，当前 chunk 仅保留领域分类与文本内容，未保留原始出处链接。

## 2. 使用范围

在补全逐条来源标注或替换为明确授权语料之前，本知识库内容**仅限竞赛评审、内部研发与教学演示使用**，不得用于商业发布或对外公共服务。

## 3. 合规处置建议（提交前建议完成）

为降低版权风险，建议按以下任一方案处置：

### 方案 A：补全来源标注（推荐）

1. 重建向量库时，在每条 chunk 的 metadata 中写入 `source` 字段（原始 URL）。
2. 在项目文档与演示中明确附注：
   > "本系统检索内容来源于公开技术资料，仅供研究/教学演示使用；如涉侵权，请联系删除。"

### 方案 B：替换为授权语料

1. 采用 CC-BY、MIT 文档许可或团队自建讲义替换现有语料。
2. 随提交附 `LICENSES` 清单，列明每份语料的授权协议与来源。

## 4. 责任声明

团队承诺在竞赛及后续使用中遵守上述限制；若因知识库内容引发版权争议，由团队负责及时处理并替换相关语料。
